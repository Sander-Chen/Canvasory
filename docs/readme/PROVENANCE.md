The images were encoded as WebP at quality 92, retaining the original pixel
dimensions. No cropping, redrawing, text replacement, or image regeneration was
performed. Source and published SHA-256 hashes, dimensions, and byte sizes are in
[assets.json](assets.json).

The comparison labels and qualitative judgments belong to the supplied image.
Original prompts, model settings, and run identities were not supplied with these
assets. The comparison is illustrative, not a controlled benchmark, evidence of
universal superiority, or a current-version acceptance receipt. The hero, process,
and output diagrams are explanatory graphics rather than application screenshots.
